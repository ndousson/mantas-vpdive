Note pour l'équipe VP Dive. Cette page est une maquette de style pour le composant documents. Elle reproduit le principe natif : un seul tableau qui bascule sur la même page via le masquage/affichage des lignes (attributs data-depth-paths / data-nav-paths côté plugin). À la racine, dossiers (bouton « Ouvrir ») et fichiers (bouton « Télécharger ») sont mêlés au même niveau. Quand on ouvre un dossier, la ligne « retour » (fil d'Ariane) s'insère sous l'en-tête du tableau, comme le plugin — l'en-tête ne bouge pas. L'arborescence gère plusieurs niveaux (ici 3 : racine → Comptes rendus du CoDir → CR Réunion 2024-2025 → fichiers) ; le fil d'Ariane s'allonge et chaque segment est cliquable pour remonter. En-tête 3 colonnes (Type masquée en mobile via d-none d-md-block), icônes dossier/PDF/Word, puces d'action. Les données sont fictives — côté VP Dive l'arborescence reste alimentée dynamiquement. Proposés à la charte : en-tête sobre, ligne de retour, puces « Ouvrir » (bleu) et « Télécharger » (cyan), survol. À noter : le plugin n'affiche pas de compteur « X fichiers » et rend l'action sous forme d'une simple icône (dossier / téléchargement) ; ici les boutons libellés sont une proposition d'amélioration de lisibilité, à valider.
